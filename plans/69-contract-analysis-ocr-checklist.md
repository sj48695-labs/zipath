## Plan #69 계약서 OCR 분석 체크리스트

- 플랜식별자: `B8FD7134`
- 출처: GitHub Issue #69 (Parent #57, Phase 5 - Task 5.1)

### 최신 구현 범위 (2026-08-26 갱신)

이슈의 최신 지시에 따라 기존 OCR 계약서 분석 구현을 유지·복구한다. 정적 체크리스트는
OCR 결과를 보조하는 기존 기능으로 함께 유지한다.

- NestJS `FileInterceptor` 기반 PNG/JPEG 계약서 이미지 업로드와 분석 API를 제공한다.
- OCR 텍스트에서 계약 유형별 주요 조항을 자동 검출하고 위험 수준·누락 조항을 반환한다.
- `/contract`에서 이미지 업로드, 분석 결과, 오류 재시도 UI를 제공한다.
- `/contract`에서 월세·전세·매매 계약 유형을 선택하고 유형별 체크리스트를 제공한다.
- 체크 상태는 계약 유형별로 브라우저 로컬 저장소에 보관한다.
- 체크리스트와 OCR 결과 모두에 “참고용이며 법적 효력 없음” 고지를 표시한다.

### 구현 항목

1. 월세·전세·매매 계약 유형 선택 UI와 유형별 체크리스트를 제공한다.
2. 선택한 유형의 체크리스트를 표시하고, 완료 상태를 유형별로 저장·복원한다.
3. 항목별 상세 설명을 펼쳐 볼 수 있게 한다.
4. 이미지 업로드 API와 OCR 텍스트 조항 검출을 제공한다.
5. 화면에 “참고용이며 법적 효력 없음” 고지를 표시한다.

### 검증 범위

- 계약 유형별 체크 상태가 서로 분리되어 저장·복원되는지 확인한다.
- 체크리스트 API의 기존 동작이 유지되는지 확인한다.
- PNG/JPEG 업로드, 10MB 제한, OCR 추출 실패 및 잘못된 계약 유형을 검증한다.
- `npm test -w @zipath/api`, `npx turbo lint`, `npx turbo build`를 실행한다.

### Phase 8 (완료): OCR 분석 기능 복구와 종단 간 검증

- 제거된 조항 키워드·분석 서비스·multipart `FileInterceptor` 엔드포인트를 복구한다.
- 웹 multipart 요청 헬퍼 및 `/contract` 이미지 업로드/결과 UI를 복구한다.
- API 단위 테스트로 OCR 텍스트 조항 검출, 파일 형식·크기 검증 및 법적 고지를 보장한다.
- 정적 체크리스트와 기존 로컬 저장 흐름을 회귀하지 않게 유지한다.
