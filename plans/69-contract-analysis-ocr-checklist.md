## Plan #69 계약서 체크리스트 가이드

- 플랜식별자: `B8FD7134`
- 출처: GitHub Issue #69 (Parent #57, Phase 5 - Task 5.1)

### 최신 MVP 범위 (2026-05-05 확정)

최신 이슈 댓글에 따라 이 이슈는 계약 유형별 정적 체크리스트 가이드로 구현한다.

- OCR, 계약서 이미지 업로드, 백엔드 분석 API는 구현하지 않는다.
- `/contract`에서 월세·전세·매매 계약 유형을 선택하고 유형별 체크리스트를 제공한다.
- 체크 상태는 계약 유형별로 브라우저 로컬 저장소에 보관한다.
- 체크리스트와 법적 고지 UI만 이슈 #69의 구현 범위로 한다.

### 구현 항목

1. 월세·전세·매매 계약 유형 선택 UI를 제공한다.
2. 선택한 유형의 체크리스트를 표시하고, 완료 상태를 유형별로 저장·복원한다.
3. 항목별 상세 설명을 펼쳐 볼 수 있게 한다.
4. 화면에 “참고용이며 법적 효력 없음” 고지를 표시한다.

### 검증 범위

- 계약 유형별 체크 상태가 서로 분리되어 저장·복원되는지 확인한다.
- 체크리스트 API의 기존 동작이 유지되는지 확인한다.
- OCR·이미지 업로드 관련 API 및 UI가 추가되지 않았는지 확인한다.
